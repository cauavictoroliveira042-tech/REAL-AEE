# Sistema AEE — verde e laranja

Projeto PHP sem banco de dados, preparado para integração posterior.

## Incluído
- Logo AEE no canto superior esquerdo
- Identidade visual verde e laranja
- Dashboard
- Alunos
- Agendamento
- Estudo de Caso
- Anexos: Anamnese, Laudo, Relatórios, Testes e Recomendações e combinados
- PAEE
- PAE colaborativo
- Usuários: Administrador, Professor e Gestão
- Layout responsivo

## Como executar
Coloque a pasta no `htdocs` do XAMPP e acesse:
`http://localhost/sistema_AEE/`

Os dados são demonstrativos. Banco, autenticação real, upload seguro e permissões deverão ser conectados posteriormente.
